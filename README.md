# 🚗 Berlin ➔ Barcelona: Roadbook & Project Hub

Проект переезда на машине с вещами и собакой из Берлина в Барселону.

---

## 📁 Структура проекта
* **[`ROADBOOK.md`](./ROADBOOK.md)** — Главный путеводитель по этапам (в стиле Esterbauer / Hikeline): паспорт дня, фотографии, интересные факты и исторические сводки, проверенные парковки и тайминги.
* **[`CHECKLIST_DEPARTURE.md`](./CHECKLIST_DEPARTURE.md)** — Чеклист подготовки перед стартом из Берлина (виньетка Швейцарии, безопасность вещей, собака).
* **`navigation/`** — Файлы для навигации:
  * `berlin_barcelona_route.kml` — карта для Google My Maps с точками и фотографиями.
* **`_archive/`** — Черновики и промежуточные расчеты.
